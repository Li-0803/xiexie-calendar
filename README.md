# 蟹蟹日历 xiexie-calendar

31 个职业、每只四帧的像素 Clawd，用纯 JS 画在 SVG 里。

**状态：**形象和动画已完成，日历功能未完成。

## 怎么看

直接打开 `index.html`。

## 文件说明

- `index.html`：职业图鉴与四帧动画预览。
- `clawd-pool.js`：像素绘制、职业数据与月历抽取逻辑。
- `calendar.html`：离线月历外观样例；邮差日可在页面顶部的 `SPECIAL_DAYS` 数组填写 `YYYY-MM-DD`。
- `GUIDE.md`：制作规范。
- `LICENSE`：代码与本项目美术设计的许可说明。

制作规范见 `GUIDE.md`。
